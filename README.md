## 🚀 Featured Projects

### 📌 Online Course Demand & Skill Trend Dashboard
> Built with Python · Pandas · Streamlit · Matplotlib · Seaborn

Analyzed 3,600+ Udemy courses dataset and created interactive dashboards with filters and charts covering price vs subscribers relationship, paid vs free course comparison, and skill demand trends.

**Key Insight:** Lower-priced courses attract more learners, while Business & Finance remains one of the most demanded categories.

---

Developed a complete database system for airline operations including ER Diagrams (Crow's Foot & Chen), DFD Level 0 & 1, Booking & Passenger Management, and SQL Query Optimization.
